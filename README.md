# yuanyu1016.github.io

这是 Yuanyu 的个人网站，使用 GitHub Pages 托管。

## 本地预览

直接用浏览器打开 `index.html` 即可查看页面。

## 部署

把本目录内容推送到仓库根目录：

```powershell
git remote add origin https://github.com/yuanyu1016/yuanyu1016.github.io.git
git branch -M main
git add .
git commit -m "Create minimal GitHub Pages site"
git push -u origin main
```

部署完成后访问：

```text
https://yuanyu1016.github.io/
```
